# skbouncer

Per-container TLS policy for Docker hosts, in C and eBPF.

Reads each container's TLS ClientHellos in the kernel, names the container
that sent them, and checks the offered versions and ciphers against a JSON
policy. Audit mode reports; enforce mode drops violating ClientHellos before
they leave the host. It also measures how much of each ClientHello the first
TCP segment carries, which post-quantum key exchange has made a real problem.

## Build

```
sudo apt install clang libbpf-dev bpftool libjansson-dev
make
./skbouncer --version
```

Needs Linux with BTF and tcx (6.6+); developed on 7.0. `src/bpf/vmlinux.h`
is a pinned BTF snapshot and is not regenerated by the build.

## Use

Loading into the kernel needs root.

```
sudo ./skbouncer --container web                          # watch
sudo ./skbouncer --container web -p policy.json           # audit
sudo ./skbouncer --container web -p policy.json --mode enforce
sudo ./skbouncer --container web -p policy.json --format json > events.jsonl
```

A policy (full spec: `policy/README.md`):

```json
{ "version": 1, "default": "deny",
  "rules": [ { "container": "web", "min_version": "1.3",
               "ciphers": ["TLS_AES_128_GCM_SHA256", "TLS_AES_256_GCM_SHA384"] } ] }
```

Each ClientHello gives one line: time, verdict, container, addresses, the
TLS versions offered, bytes seen (`1455/1561` when the first segment held
only part of it), ciphers, and the reason for the verdict. The verdict is
`allow`, `violation`, or `unknown` when the part a rule needs was not in the
first segment. JSON mode prints one object per event with the raw values;
status goes to stderr. On exit it prints how many ClientHellos were
detected, delivered, and lost.

Enforcement works only on a container's veth, blocks only inside that
container's cgroup, and refuses the root cgroup. It ends with the process:
a stopped or crashed skbouncer leaves nothing attached. Known limits are in
`policy/README.md`.

## Layout

```
docs/CODEBASE.md      how the code fits together; start here to review it
include/skbouncer.h   event and rule formats shared by kernel and userspace
src/bpf/              tcx program: detect, measure, walk, judge, drop
src/user/             CLI, loader, container lookup, policy, enforcement, output
policy/               policy spec and example
scripts/verify-*.sh   one verifier per milestone; each reruns the earlier ones
tests/                the verifiers' oracles and TLS test image
scripts/loop.sh       development loop, with scripts/guard.sh
eval/census/          ClientHello sizes and split points across real clients
```
