# skbouncer

TLS handshake monitor with per-container policy enforcement, in C and eBPF.

Reads TLS ClientHello/ServerHello from a tc clsact hook, attributes each
connection to its container, and checks it against a JSON policy of
permitted cipher suites and protocol versions. Audit and enforce modes.

## Build

```
sudo apt install clang libbpf-dev bpftool libjansson-dev
make
```

`src/bpf/vmlinux.h` is committed as a pinned BTF snapshot and is not
regenerated by the build.

## Run

Loading BPF requires root.

```
sudo ./skbouncer                          # load only, do not attach
sudo ./skbouncer -i ens33                 # host egress
sudo ./skbouncer -i vethXXXX -d ingress   # one container, pre-NAT
sudo ./skbouncer --help
```

One line per ClientHello: monotonic timestamp, interface, direction, cgroup
id, 4-tuple, TLS record length, how many body bytes the segment carrying the
record header actually holds, and why it stopped there (`none` or
`segment`).

### Watching one container

A bridged container's outbound packet reaches the physical interface already
forwarded and SNATed, so there it shows the host address and no cgroup id.
The same packet is *ingress* on the host side of the container's veth, where
it is still pre-NAT. One veth is one container, so that is the attachment
point to use:

```
IDX=$(docker exec <cid> cat /sys/class/net/eth0/iflink)
VETH=$(ip -o link | awk -v i="$IDX" -F': ' '$1+0==i {split($2,a,"@"); print a[1]}')
sudo ./skbouncer -i "$VETH" --direction ingress
```

`--network host` containers have a local socket and are visible at host
egress like any other process.

On exit it prints how many ClientHellos the kernel detected, how many were
delivered, and how many were lost to a full ringbuf. The last is the
coverage denominator: a lost event must not look like a connection that
never happened.

Enforce mode requires `--cgroup` and refuses the root cgroup.

## Layout

```
include/skbouncer.h   types shared by BPF and userspace
src/bpf/              tc clsact program (egress or ingress)
src/user/             loader, policy, container resolution, CLI
scripts/              development loop and its invariant guard
```
